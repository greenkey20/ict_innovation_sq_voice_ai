# 이슈 기록 (개발환경_이슈노트.md)

환경 문제(패키지 설치, 커널/환경 불일치, 경로, 버전 충돌 등)를 `개발환경_이슈노트.md`에 **기존 이슈와 같은 형식**으로 기록한다. CLAUDE.md의 규칙에 따라 환경 문제는 CLAUDE.md가 아니라 **이슈노트에** 적는다.

## 지켜야 할 컨벤션 (CLAUDE.md 요약)

- 이 수업은 **`voice-ai` conda 환경(Python 3.11, `/opt/anaconda3/envs/voice-ai`)만** 쓴다. `base`/`tf_env`/`study` 등은 무관하다. 커널 확인: `import sys; print(sys.executable)`.
- 노트북에서 설치는 **`!pip` 대신 `%pip install`** 로 적는다(`!pip`는 노트북 커널이 아닌 셸의 파이썬에 설치될 수 있음: 이슈 #3, #13).
- 설치 전에는 `pip install --dry-run`으로 먼저 확인하고, **numpy는 1.26.4 유지**(TensorFlow 2.16.2와 numpy 2.x 충돌: 이슈 #9). 이 컴퓨터는 macOS 13.7(Intel)이라 `faiss-cpu<1.8` 같은 고정이 필요할 수 있다.
- 경로는 노트북 폴더 기준 상대경로(`../dataset/...`)로 적고, 개인 경로(`/Users/...`)나 **API 키는 기록하지 않는다**(`.env`는 저장소 루트, 절대 커밋 금지).
- 정확성 규칙: 확인하지 않은 원인·효과는 **"추정"/"확인 못 한 것"** 으로 표시한다.

## 수행 순서

1. **기존 형식 파악.** `개발환경_이슈노트.md`를 읽고 다음을 확인한다.
   - 구조: `## 이슈 로그` 아래에 날짜 소제목(`### 2026-10-19`)이 있고, 그 아래 `#### 번호. 제목` 이슈가 이어진다. 마지막에 `## 자주 쓰는 진단 커맨드 모음`이 있다.
   - **마지막 번호**를 찾아 +1을 새 번호로 쓴다(`grep -n '^#### [0-9]'`).
   - 이슈의 본문은 글머리표 필드로 쓴다. 자주 쓰는 필드: `상황`, `증상`, `원인`, `해결`(또는 `실행한 명령`), `확인 필요`, `확인 못 한 것`, `참고`. 이슈에 따라 필요한 것만 쓴다. 이슈 제목에 `(발생: YYYY-MM-DD)`를 붙이는 경우도 있다.
2. **이슈 파악.** 인자(이슈 제목)가 있으면 제목으로 쓰고, **내용은 사용자에게 물어서** 파악한다. 물어볼 것(이미 대화에 있는 것은 다시 묻지 않는다):
   - 증상(오류 문구 원문), 발생한 노트북/셀과 날짜
   - 이미 시도한 것과 결과, 해결했는지 여부
   - 원인이 확인됐는지 추정인지
3. **필요하면 직접 확인한다**(읽기 전용 명령만 먼저): `sys.executable`, `pip show <패키지>`, `pip check` 등. **설치·업그레이드는 사용자 승인 없이 실행하지 않는다.** 실행했다면 어떤 환경에서 무엇을 확인했는지 기록한다.
4. **새 섹션 작성.**
   - 오늘 날짜 소제목(`### YYYY-MM-DD`, 시스템이 알려 준 오늘 날짜)이 이미 있으면 그 아래 마지막 이슈 뒤에, 없으면 새 날짜 소제목을 `## 자주 쓰는 진단 커맨드 모음` **앞**에 만든다.
   - 기존 이슈와 같은 문체(한국어 평서문·`-` 글머리표, 명령은 코드 블록)로 쓴다. 설치 명령은 `%pip install ...`로 적고 버전·확인 날짜를 함께 적는다.
   - 도움이 되는 진단 명령이 새로 생겼으면 `자주 쓰는 진단 커맨드 모음` 목록에도 추가할지 사용자에게 묻는다.
5. **결과를 보여 준다.** 추가한 섹션과 번호를 요약해서 보고한다. 파일에는 `Edit`로 해당 부분만 삽입한다(파일 전체를 다시 쓰지 않는다).
6. 커밋하지 않는다(`/커밋준비`에서 사용자 승인 후).

## 이슈 섹션 템플릿

```markdown
#### N. <한 줄 제목> (발생: YYYY-MM-DD)

- **상황**: <어느 노트북/셀에서 무엇을 하다가>
- **증상**: `<오류 문구 원문>`
- **원인**: <확인한 원인. 확인하지 못했으면 "추정:" 으로 표시>
- **해결**:
  ```python
  %pip install <패키지>   # voice-ai 커널 기준
  ```
  - <왜 이렇게 하는지, 주의할 점(numpy 1.26.4 유지 등)>
- **확인 못 한 것**: <직접 실행해 보지 않은 것>
- **참고**: <관련 이슈 번호(#3 등), 되돌리는 방법>
```
