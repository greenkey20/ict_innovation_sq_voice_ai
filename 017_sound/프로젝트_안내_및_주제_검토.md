## 4. 평가와 코멘트

### 4.1 강사님 기준과의 적합성
- **OpenAI API 기반** 범주에 들어갑니다. 수업 `013_openai_api`에서 이미 **STT(`transcribe_korean`)와 TTS(`text_to_wav`)** 를 다뤘고 **license-key가 제공**됩니다 **[확인]**.
- 음성 과정에서 이어서 배울 것(이 저장소 README 기준 **[확인]**): Whisper 음성 인식, **WER·CER와 오류 분석**, 음성 합성의 전체 흐름. 이 내용이 아이디어의 **채점(WER/CER)** 과 직접 연결됩니다.
- **위험:** 외부 서비스(발음 평가 API, 음악 인식 API, 가사 API, 음악 카탈로그 API)는 **제공되는 키가 없고 약관·요금·지원 언어가 불확실**합니다. 40시간에서 **키 발급과 약관 확인에만 시간이 새기 쉽습니다.** 필수 기능은 **수업에서 제공받는 OpenAI API만으로** 동작하도록 설계하는 것을 권합니다 **[추정]**.

### 4.2 아이디어의 강점
- **문제의 출처가 분명**합니다(좋아하는 노래의 뜻을 알고 따라 부르고 싶다). 발표에서 "왜 만들었나"를 설명하기 쉽습니다.
- **듣기(TTS → 받아쓰기)와 말하기(녹음 → STT) 두 가지 음성 활용**을 모두 쓰고, 수업의 STT·TTS·WER/CER·음향 처리(017)와 겹칩니다.
- 장표의 포트폴리오 목적(경험 증명, 개발 프로세스 이해)에 맞춰 **"실험과 평가를 포함한 음성 AI 프로젝트"** 로 만들 수 있습니다.

### 4.3 위험과 해결 방향
| 위험 | 설명 | 해결 방향 |
|---|---|---|
| **데이터(가사) 확보 + 저작권** | 가사와 음원은 저작권 대상일 수 있음. 이 저장소는 공개 | **직접 만든 예문**, 공개·자유 이용이 확인된 문장으로 시작. 상업 가사/음원은 **저장소·발표 자료에 넣지 않음**. "개인 학습용 입력 기능"으로만 두는 안은 약관을 확인한 뒤 판단 |
| **STT 일치 ≠ 발음 정확** | STT는 문맥으로 의도한 문장을 맞힐 수 있음 | 채점 지표를 **"단어 일치도(WER/CER)"** 로 이름 붙이고 "발음 평가"라고 주장하지 않음 |
| **범위 초과** | 검색·가사·TTS·받아쓰기·녹음·평가·PWA를 모두 넣음 | MVP를 **핵심 흐름 하나**로 제한(아래 4.4) |
| **채점의 정의** | 점수의 의미가 모호함 | 단어 일치도 / 발음 정확도 / 노래 실력을 **구분**해서 앞의 둘만 다룸 |
| **API 의존** | 한도·키·모델 이름이 바뀔 수 있음 | 수업 키로 **1일차에 실제 호출 테스트**, 대체 경로(직접 입력, 녹음 파일 업로드) 준비 |

### 4.4 제안 MVP (노래 기능은 모두 확장)
```text
[입력] 학습 문장 선택/입력 (직접 만든 예문, 사용 권한이 확인된 문장)
   │
   ├─ 학습 1 (듣기): OpenAI TTS로 재생 → 사용자가 받아쓰기 → 정답과 비교해 WER/CER·틀린 단어 표시
   │
   └─ 학습 2 (말하기): 사용자가 문장을 읽어 녹음 → STT로 인식 → 기준 문장과 WER/CER 비교
[추가 실험 1개] TTS 음성과 내 녹음의 차이를 파형·길이·SR·Mel로 비교 (수업 017 연결)
[확장] 노래 검색(텍스트) → 소리 검색 → 노래 채점
```
- **받아쓰기(학습 1)** 는 외부 STT가 없어도 되고, 키보드 입력을 정답과 비교하는 것이라 **가장 안전한 핵심 기능**입니다 **[추정]**.
- **"노래 검색(텍스트)"** 은 가사 데이터 문제 때문에 MVP에서 빼고, 문장을 직접 넣는 구조로 시작하는 편이 안전합니다. 학습 기능을 **검색 방식과 독립적으로** 설계하면 나중에 붙일 수 있습니다(두 LLM 답변도 같은 조언).
- **실험 아이디어(깊이 확보):** 짧은 문장 5~10개에 대해 ① TTS 음성, ② 내가 읽은 녹음, ③ STT 인식 결과, ④ WER/CER, ⑤ 파형·길이·SR·Mel 스펙트로그램을 기록합니다. **스펙트로그램이 다르다고 발음이 나쁘다고 판정하지는 않습니다**(시각화와 평가는 다른 근거).
