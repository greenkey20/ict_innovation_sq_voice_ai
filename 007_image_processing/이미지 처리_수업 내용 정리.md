## 1. MobileNetV2 전이학습

**하는 일**: 고양이/개 이진 분류. `006_cnn`의 `DogCat_V2.0`과 같은 문제지만 푸는 방식이 다름.

- `MobileNetV2(weights='imagenet', include_top=False)` — ImageNet(수백만 장)으로 이미 학습된 모델을 가져오되, 맨 위 분류층만 떼어냄. 이미지에서 선·질감·형태 같은 **특징을 뽑는 부분만 재활용**.
- 그 위에 `GlobalAveragePooling2D → Dense(1024) → Dense(1, sigmoid)`를 새로 얹음. 이것이 고양이/개를 가르는 층.
- `layer.trainable = False` — 가져온 부분은 **얼려서 학습하지 않고**, 새로 얹은 층만 학습.
- 효과: 데이터가 적어도(여기선 35장씩) 정확도가 빨리 오름. 저장된 출력에서 1 epoch 만에 `val_accuracy 0.93`이 나온 이유. 처음부터 CNN을 만드는 방식(`DogCat`, `CNN_Basic_MNIST`)보다 훨씬 적은 데이터로 가능.

## 2. YOLO 객체 탐지

**분류와의 차이**: 분류는 "이 사진은 고양이"처럼 사진 한 장에 답 하나. 객체 탐지는 한 사진에서 **여러 물체에 박스를 치고 각각 이름을 붙임**. 두 YOLO 모두 **학습은 하지 않고** 미리 학습된 모델에 사진을 넣어 결과만 받음(추론).

### 2-1. YOLOv3 (OpenCV `cv2.dnn`으로 직접 구현)

`yolov3.cfg`(구조) + `yolov3.weights`(학습된 값) + `coco.names`(이름표)를 `cv2.dnn.readNetFromDarknet`으로 불러서 쓴다. 파일명에 `TF`가 들어 있지만 TensorFlow가 아니라 **OpenCV만 사용**한다.

처리 순서 (노트북의 줄별 주석 참고):
1. 이름표와 모델을 불러온다.
2. 사진을 읽어서 `blobFromImage`로 모델 입력 형태(416×416, 값 0~1, RGB)로 바꾼다.
3. `net.forward`로 후보 박스를 받는다. 한 줄이 `[중심x, 중심y, 너비, 높이, 물체일 확률, 80개 클래스 점수]`이고, 좌표는 사진 크기 대비 비율(0~1)이다. 후보는 약 1만 개(13²+26²+52²에 3을 곱한 값, YOLOv3·416 입력 기준 계산값).
4. 클래스 점수 최고값이 `0.5`를 넘는 후보만 남긴다. 중심 좌표를 왼쪽 위 모서리 좌표로, 비율을 실제 픽셀로 바꾼다.
5. **NMS(비최대 억제)** — 같은 물체에 겹쳐 잡힌 박스를 확신도가 가장 높은 하나만 남긴다. `0.4`는 40% 넘게 겹치면 같은 물체로 본다는 뜻.
6. 박스와 `이름: 확신도`를 사진 위에 그리고, OpenCV(BGR)와 matplotlib(RGB)의 색 순서가 다르므로 `cvtColor`로 바꿔서 보여주고 저장한다.

> 참고: 이 코드는 확신도를 클래스 점수만으로 쓰고 5번째 값(물체일 확률)은 쓰지 않는다. 입문 예제에서 흔한 방식이며, 더 엄밀하게는 두 값을 곱해서 쓰기도 한다.

### 2-2. YOLOv8 (`ultralytics` 라이브러리)

```python
from ultralytics import YOLO
model = YOLO("yolov8n.pt")      # n = nano, 가장 가볍고 빠른 모델 (s, m, l, x로 갈수록 크고 정확)
results = model(img_path)       # 전처리 + 추론 + NMS까지 한 줄
```

- v3에서 직접 짠 **전처리, 좌표 변환, 임계값 필터링, NMS, 박스 그리기를 라이브러리가 전부 처리**한다. `results[0].boxes`에서 `cls`(물체 번호), `conf`(확신도)를 꺼내 쓰고, `results[0].show()` / `.save()`로 결과를 보고 저장한다.
- v3 코드는 "내부에서 무슨 일이 일어나는지"를 보여주는 학습용, v8은 실제로 쓰는 편한 방법이라고 보면 된다.
- 확신도 하한은 v3 코드의 `0.5`와 달리 ultralytics 기본값(약 0.25로 알고 있음)이 쓰여서, 같은 사진에서도 v8이 더 많은 박스(확신도 0.45 같은 낮은 것까지)를 잡는다.
- 설치: `voice-ai` 커널에서 `!pip install ultralytics` (커널 문제로 설치가 안 잡히면 `개발환경_이슈노트.md` #3 참고).

## 이 내용은 CNN과 관련 있나? 006에 두면 되나?

**둘 다 CNN 기반이지만, 006(CNN 기초)과는 다른 주제**입니다.

| | 성격 | 006(CNN)과의 관계 |
|---|---|---|
| MobileNetV2 | 전이학습 | CNN 모델을 **재활용하는 방법**. CNN을 배운 뒤에 오는 주제 |
| YOLO | 객체 탐지 | CNN 기반이지만 **별개 주제**(분류가 아니라 위치 + 이름 찾기). 학습 없이 사전학습 모델을 그대로 사용 |

그래서 006(CNN 기초: MNIST, DogCat)과 분리해서 별도 폴더로 두는 구성이 자연스럽습니다. 두 주제의 공통점은 "미리 학습된 모델을 가져다 쓴다"는 점입니다.

### CNN은 기본적으로 이미지 처리용인가?

네. 이웃한 픽셀끼리 의미가 있다는 점(선, 모서리, 질감)을 이용해 작은 필터(예: 3×3)로 이미지를 훑으며 특징을 뽑는 구조라 이미지에 잘 맞습니다. 같은 필터를 이미지 전체에 적용하므로 물체가 어디 있든 찾을 수 있고 파라미터도 적게 듭니다. 층이 깊어질수록 선 → 모서리/질감 → 형태 → 물체처럼 점점 큰 특징을 학습합니다. `DogCat_V2.0`처럼 이미지를 1차원으로 펴서 `Dense`에 넣으면 위치 정보가 사라지지만, CNN은 위치 관계를 그대로 살립니다.

이미지 전용은 아닙니다. 음성은 파형을 스펙트로그램(시간 × 주파수의 2차원 그림)으로 바꾸면 이미지처럼 CNN에 넣을 수 있고, 이 과정 5주차의 Spectrogram, Mel/Log-Mel 특징이 그 입력입니다. 그래서 여기서 배우는 CNN과 사전학습 모델 활용은 이후 음성 AI 단계의 바탕이 됩니다.

> 폴더 이름의 `image_processing`은 넓은 의미로 쓴 것이다. 이미지 처리(필터링 등 픽셀 연산)라기보다 딥러닝 기반 컴퓨터 비전(전이학습, 객체 탐지)에 가깝다.
